# Unique Focus Association (UFA) 🇰🇪

The official website for **Unique Focus Association (UFA)** — a community-based organization in Kenya dedicated to empowering youth through mentorship, leadership development, talent incubation, and community impact.

---

## 🎯 About the Platform

This web platform serves as the digital home for UFA members, partners, and the general public, providing:

- **Programs & Initiatives:** Details on mentorship streams, leadership workshops, sports tournaments, and community outreach.
- **Events & RSVP:** Real-time updates and registration for upcoming association events and conferences.
- **Membership Registration:** An online application gateway for new members and volunteers across Kenya.
- **Official Merchandise:** Catalog of branded association apparel with direct WhatsApp order placement.
- **Administrative Portal:** A secure dashboard for association leaders to manage events, inventory, leadership profiles, and review member applications.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, React Router v7, React-Bootstrap, Lucide Icons
- **Backend & Storage:** Supabase (PostgreSQL, Authentication, and Media Storage)

---

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/your-username/ufa.git
cd ufa
npm install
```

### 2. Environment Setup
Create a `.env` file based on `.env.example`:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```
*(The website includes offline fallbacks and runs even without active Supabase keys for development).*

### 3. Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
